# СӨЖ 7 бойынша есеп

## Тақырыбы

Python бағдарламасындағы қателерді debugger және unit-тесттер көмегімен анықтау және түзету.

## Жұмыстың мақсаты

Бағдарламадағы үш қатені табу, олардың себептерін талдау, түзетілген нұсқаны дайындау және автоматты тесттер арқылы дұрыстығын тексеру.

## Зерттелген бағдарлама

Бастапқы нұсқа: [01_buggy.py](01_buggy.py).

Түзетілген нұсқа: [02_fixed.py](02_fixed.py).

Бағдарламада үш функция бар:

- `average(numbers)` — сандардың орташа мәнін есептейді;
- `final_price(price, percent)` — жеңілдіктен кейінгі бағаны есептейді;
- `maximum(numbers)` — тізімдегі ең үлкен санды табады.

## Қателерді анықтау

### 1. Жеңілдікті есептеу қатесі

Бастапқы кодта:

```python
discount = price * percent
```

`percent` пайыздық мән болғандықтан, оны 100-ге бөлу керек. `1000` теңге және `20%` үшін бастапқы бағдарлама `20000` теңге жеңілдік есептейді.

Түзетілген код:

```python
discount = price * percent / 100
```

Нәтиже: `1000` теңге және `20%` жеңілдік кезінде соңғы баға `800.0` теңге.

### 2. Теріс сандардан максимум табу қатесі

Бастапқы кодта:

```python
largest = 0
```

Егер тізімдегі барлық сандар теріс болса, олардың ешқайсысы `0`-ден үлкен болмайды. Мысалы, `[-8, -3, -5]` тізімі үшін функция қате түрде `0` қайтарады.

Түзетілген код бастапқы мәнді тізімнің бірінші элементінен алады:

```python
largest = numbers[0]
```

Нәтиже: `maximum([-8, -3, -5])` шақыруы `-3` қайтарады.

### 3. Бос тізімдегі орташа мән қатесі

Бастапқы кодта бос тізім үшін:

```python
sum([]) / len([])
```

яғни `0 / 0` орындалады және `ZeroDivisionError` пайда болады.

Түзетілген нұсқада бос тізім алдын ала тексеріледі:

```python
if not numbers:
    raise ValueError("Орташа мән үшін кемінде бір сан қажет.")
```

Осылайша түсінікті `ValueError` қатесі беріледі және негізгі бағдарлама оны өңдейді.

## Debugger қолдану

Breakpoint келесі жолдарға қойылды:

- `final_price` функциясындағы `discount` есептелетін жолға;
- `maximum` функциясындағы `largest` және салыстыру жолдарына;
- `average` функциясындағы бос тізімді тексеру жолына.

VS Code-та қолданылған негізгі командалар:

- `F9` — breakpoint қою немесе алып тастау;
- `F5` — debugger-ді іске қосу;
- `F10` — Step Over, ағымдағы жолды орындау;
- `F11` — Step Into, функцияның ішіне кіру;
- `Shift+F11` — Step Out, функциядан шығу.

Debugger кезінде `price`, `percent`, `discount`, `current`, `largest` және `len(numbers)` айнымалылары бақыланды.

## Unit-тесттер

Тесттер [test_program.py](test_program.py) файлында орналасқан. Тесттер бастапқы қателерді де, түзетілген функциялардың дұрыс жұмысын да тексереді.

Іске қосу командасы:

```bash
python -m unittest discover -s sro7 -p 'test_*.py' -v
```

Тексеру нәтижесі:

```text
Ran 12 tests
OK
```

Тесттер қалыпты жағдайларды, теріс сандарды, бір элементті тізімді, бос тізімді, `0%` және `100%` жеңілдікті, сондай-ақ жарамсыз мәндерді қамтиды.

## Қорытынды

Debugger арқылы үш қатенің нақты себебі айнымалылардың мәндерін қадамдап бақылау арқылы анықталды. Қателер түзетілгеннен кейін барлық 12 unit-тест сәтті өтті. Нәтижесінде бағдарлама қалыпты және шекаралық жағдайларда дұрыс жұмыс істейді.
