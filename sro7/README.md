# СӨЖ 7 — Python бағдарламасын жөндеу

Мақсат: кемінде үш қатені debugger арқылы анықтау, түзету және автоматты
тесттермен тексеру. Қосымша кітапханаларды орнату қажет емес.

## 1. Алдымен қате нұсқа

[01_buggy.py](01_buggy.py) — орындалу қатесі және екі түрлі логикалық қатесі бар
бастапқы бағдарлама. Жоба түбірінен орындаңыз:

```bash
python3 sro7/01_buggy.py
```

Алдымен баға `-19000`, ең үлкен сан `0` болып шығады. Содан кейін бос тізімді
өңдегенде `ZeroDivisionError` пайда болады. Бұл — зерттеуге арналған күтілетін нәтиже.

## 2. Breakpoint және айнымалыларды қадамдап тексеру

Breakpoint қате нұсқада да, түзетілген нұсқада да қойылады.
Алдымен қатенің себебін анықтап, кейін түзетілген мәндерді салыстырыңыз.
Төмендегі қадамдар нақты орындалды. Терминал жазбасы:
[debugger_session.md](debugger_session.md).

```bash
python3 -m pdb sro7/01_buggy.py
```

1. `b 13`, `b 22`, `b 7` командаларымен үш тоқтау нүктесін орнатыңыз.
2. `c` арқылы 13-жолға жетіңіз. `p price, percent` нәтижесі: `(1000, 20)`.
   `n` командасымен бір қадам орындаңыз. `p discount` нәтижесі: `20000`.
   Жеңілдік `200` болуы керек, демек пайызды жүзге бөлу қажет.
3. `c` арқылы 22-жолға жетіңіз. `p current, largest` нәтижесі: `(-8, 0)`.
   `n` арқылы салыстыруды орындаңыз: `largest` өзгермейді.
   Келесі `c` қадамдарында мәндер `(-3, 0)` және `(-5, 0)` болады.
   Нөл тізімде жоқ, бірақ нәтиже ретінде қайтарылады.
4. `c` арқылы 7-жолға жетіңіз. `p numbers, len(numbers)` нәтижесі: `([], 0)`.
   `n` орындалғанда `ZeroDivisionError` шығады. `q` арқылы шығыңыз.

VS Code ішінде де осы жолдарға breakpoint қойып, `F5`, Step Over (`F10`),
Step Into (`F11`), Variables және Watch құралдарын қолдануға болады.
Watch өрнектері: `price`, `percent`, `discount`, `current`, `largest`, `len(numbers)`.

## 3. Содан кейін дұрыс нұсқа

[02_fixed.py](02_fixed.py) — түзетілген бағдарлама:

```bash
python3 sro7/02_fixed.py
```

Нәтижелері: баға `800.0`, максимум `-3`, орташа мән `20.0`.
Бос тізім үшін түсінікті қазақша хабарлама көрсетіледі.
Орташа мәні жоқ бос тізімге жасанды сан тағайындалмайды: функция `ValueError`
береді, ал негізгі бағдарлама оны өңдейді.

### Дұрыс нұсқадағы breakpoint

```bash
python3 -m pdb sro7/02_fixed.py
```

1. `b 16`, `b 25`, `b 27`, `b 6` командаларын енгізіңіз.
2. `c` арқылы 16-жолға жетіңіз. `p price, percent` → `(1000, 20)`.
   `n`, содан кейін `p discount` → `200.0` (қате нұсқада `20000`).
3. `c` арқылы 25-жолға жетіңіз. `n`, содан кейін `p largest` → `-8`.
   `c` арқылы 27-жолға жетіңіз: `p current, largest` → `(-3, -8)`.
   Екі рет `n` орындап, `p largest` тексеріңіз: `-3`.
   Келесі `c` кезінде `(-5, -3)` болады; максимум өзгермейді.
4. `c` арқылы 6-жолға жетіңіз. Алғашқы шақыруда `numbers == [10, 20, 30]`.
   `n` арқылы бос еместігін тексеріңіз. Келесі `c` бос тізіммен шақыруға жеткізеді:
   `p numbers, len(numbers)` → `([], 0)`.
   Екі рет `n` кезінде `ValueError` көрінеді. `c` арқылы жалғастырыңыз:
   негізгі бағдарлама қатені өңдеп, қазақша хабарлама шығарады. `q` арқылы шығыңыз.

VS Code ішінде дұрыс нұсқаның **6, 16, 25, 27-жолдарына** breakpoint қойыңыз.
Әр файлды бөлек `F5` арқылы іске қосып, `F10` және Variables/Watch арқылы салыстырыңыз.
Толық екі сеанс [debugger_session.md](debugger_session.md) ішінде сақталған.

## 4. Қысқаша есеп

| Бастапқы қате | Түпкі себеп | Түзету | Қате → дұрыс нәтиже |
| --- | --- | --- | --- |
| Орындалу қатесі: бос тізімнің орташа мәні | `len([]) == 0`, нөлге бөлу | Бос тізімді алдын ала тексеру, `ValueError` хабарламасын өңдеу | Бақылаусыз тоқтау → түсінікті хабарлама |
| Логикалық қате: жеңілдік | Пайыз үлеске айналдырылмаған | `price * percent / 100` | `-19000` → `800.0` |
| Алгоритмнің бастапқы мән қатесі: максимум | `largest = 0` теріс сандардан үлкен | Бастапқы мәнді `numbers[0]` арқылы алу, бос тізімді тексеру | `0` → `-3` |

## 5. Автоматтандырылған тесттер

[test_program.py](test_program.py) файлында 12 тест бар:
3 тест бастапқы қателерді қайталайды, 9 тест түзетілген нұсқаны тексереді.
Бастапқы нұсқаға арналған тесттердің өтуі оның дұрыс екенін білдірмейді:
олар әдейі қате нәтиже мен exception бар екенін дәлелдейді.

```bash
python3 -m unittest discover -s sro7 -p 'test_*.py' -v
```

Нақты тексеру нәтижесі: **12 тесттің 12-сі өтті (OK)**.
Тексерулер қалыпты есептеуді, бос тізімді, теріс сандарды, бір элементті,
0% және 100% жеңілдікті, жарамсыз баға мен пайызды қамтиды.

Қорытынды: debugger айнымалылардың нақты мәндерін көрсетіп, үш қатенің түпкі
себебін анықтауға көмектесті. Түзетілген нұсқа барлық автоматты тексеруден өтті.
