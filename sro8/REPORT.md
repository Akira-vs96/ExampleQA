# СӨЖ 8 бойынша есеп

## Тақырыбы

Интернет-дүкен модулінің сапасын статикалық талдау, типтерді тексеру және автоматты тесттер арқылы бағалау.

## Жұмыстың мақсаты

Интернет-дүкендегі есептеу қателерін анықтау, код сапасын тексеру құралдарын қолдану және түзетілген модульдің сенімділігін тесттермен дәлелдеу.

## Зерттелген бағдарлама

Бастапқы нұсқа: [01_buggy.py](01_buggy.py).

Түзетілген нұсқа: [02_fixed.py](02_fixed.py).

Модульдегі негізгі функциялар:

- `line_total(price, quantity)` — тауарлардың жалпы құнын есептейді;
- `discounted_total(subtotal, percent)` — жеңілдіктен кейінгі соманы есептейді;
- `shipping_cost(total)` — жеткізу құнын анықтайды.

## Анықталған мәселелер

### 1. Тауар құнын есептеу қатесі

Бастапқы нұсқада баға мен сан қосылған. Дұрыс формула:

```python
price * quantity
```

`2000 × 3` үшін дұрыс нәтиже — `6000` теңге.

### 2. Жеңілдікті есептеу қатесі

Пайыз 100-ге бөлінбей қолданылған. Дұрыс формула:

```python
subtotal * (100 - percent) // 100
```

`10000` теңгеге `20%` жеңілдік қолданылса, нәтиже `8000` теңге болады.

### 3. Тегін жеткізу шекарасы

Талап бойынша жеңілдіктен кейінгі сома `10000` теңге немесе одан жоғары болса, жеткізу тегін болуы керек. Сондықтан шартта `>= 10000` қолданылады.

Нәтижелер:

- `9999` теңге → `1000` теңге жеткізу;
- `10000` теңге → тегін жеткізу;
- `10001` теңге → тегін жеткізу.

### 4. Код сапасы және типтер

Ruff бастапқы кодтағы қолданылмаған `math` импортын анықтады. Mypy функциялардағы типтік аннотациялардың жоқтығын және `shipping_cost` функциясының бүтін сан орнына мәтін қайтаратынын көрсетті.

Түзетілген нұсқада барлық негізгі функцияларға параметр және қайтарым типтері қосылды. Теріс баға, нөлдік сан және `0–100` аралығынан тыс пайыз үшін `ValueError` қолданылады.

## Қолданылған құралдар

- Ruff — код стилі мен қарапайым қателерді тексеру;
- mypy — типтерді статикалық тексеру;
- pytest — автоматты unit-тесттерді орындау.

Түзетілген кодты тексеру командалары:

```bash
python -m ruff check --config sro8/pyproject.toml sro8/02_fixed.py sro8/test_shop.py sro8/__init__.py
python -m mypy --config-file sro8/pyproject.toml sro8/02_fixed.py
python -m pytest -q -c sro8/pyproject.toml sro8
```
