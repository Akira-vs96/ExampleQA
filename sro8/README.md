# СӨЖ 8 — интернет-дүкен модулінің сапасын талдау

Тақырып: интернет-дүкен. Модуль үш негізгі функциядан тұрады:
`line_total` — тауар құны, `discounted_total` — жеңілдіктен кейінгі сома,
`shipping_cost` — жеткізу құны. Барлық ақша мәндері бүтін теңгемен беріледі.
Жеткізу жеңілдіктен кейінгі сома **кемінде 10000 теңге** болғанда тегін,
қалған жағдайда 1000 теңге. Жеңілдіктен кейінгі сома төмен қарай бүтінге дөңгелектенеді.

## 1. Алдымен бастапқы нұсқа

[01_buggy.py](01_buggy.py) файлын жоба түбірінен орындаңыз:

```bash
python3 sro8/01_buggy.py
```

Нәтиже: `2003`, `-190000`, `1000`. Бұл мәндер талапқа сәйкес емес.

## 2. Содан кейін түзетілген нұсқа

[02_fixed.py](02_fixed.py) файлында есептеулер түзетіліп, кіріс мәндерінің
тексерістері және барлық үш функцияға параметр мен қайтарым типтері енгізілген.

```bash
python3 sro8/02_fixed.py
```

Сол кіріс мәндері үшін дұрыс нәтиже: `6000`, `8000`, `0`.

## 3. Ruff, mypy және pytest арқылы тексеру

Жобадағы дайын виртуалды ортаға тәуелділіктерді орнату:

```bash
backend/.venv/bin/python -m pip install -r sro8/requirements-dev.txt
```

Бастапқы кодты тексеру (екі команда да анықталған қателерге байланысты `1` кодын береді):

```bash
backend/.venv/bin/python -m ruff check --config sro8/pyproject.toml sro8/01_buggy.py
backend/.venv/bin/python -m mypy --config-file sro8/pyproject.toml sro8/01_buggy.py
```

Түзетілген кодты және тесттерді тексеру:

```bash
backend/.venv/bin/python -m ruff check --config sro8/pyproject.toml sro8/02_fixed.py sro8/test_shop.py sro8/__init__.py
backend/.venv/bin/python -m mypy --config-file sro8/pyproject.toml sro8/02_fixed.py
backend/.venv/bin/python -m pytest -q -c sro8/pyproject.toml sro8
```

mypy `strict = true` режимінде жұмыс істейді. Ruff түзетілген модуль мен тесттерді,
mypy түзетілген модульді тексереді. Құралдардың нақты нұсқалары, командалары,
шығару мәтіні және шығу кодтары [analysis_results.md](analysis_results.md) ішінде.

## 4. Қысқаша есеп: мәселелер, себептер және түзетулер

| Мәселе | Анықтау тәсілі және түпкі себеп | Түзету | Дұрыстығын дәлелдеу |
| --- | --- | --- | --- |
| Қолданылмаған импорт | Ruff: `F401`, `math` еш жерде қолданылмайды | Импорт жойылды | Ruff: 0 қате |
| Типтік аннотациялар жоқ | mypy strict: `no-untyped-def`, функция келісімшарты анық емес | Параметрлер мен қайтарымға `int` енгізілді | mypy: 0 қате |
| Жеткізу құнының типі қате | mypy: `return-value`, `int` орнына `str` қайтарылады | `"0"` орнына `0` | `test_shipping_boundary_and_type` типті де тексереді |
| Тауар құны қате есептеледі | Логикалық тексеру: баға мен сан қосылған | `price * quantity` | `2000 × 3`: `2003` → `6000` |
| Жеңілдік қате есептеледі | Логикалық тексеру: пайыз жүздік үлеске айналмаған | `subtotal * (100 - percent) // 100` | 10000 теңге, 20%: `-190000` → `8000` |
| Тегін жеткізу шекарасы қате | Шекаралық тест: `>` шарты 10000 теңгені қоспайды | `>= 10000` | 9999 → 1000, 10000 → 0, 10001 → 0 |
| Жарамсыз кіріс қабылданады | Кодты қарау: теріс баға, нөлдік сан, қате пайыз тексерілмейді | `ValueError` арқылы тексеру қосылды | Жарамсыз кірістерге арналған pytest тесттері |

Ruff пен mypy бизнес-логиканың барлық қатесін анықтамайды. Сондықтан есептеу
және жеткізу шекарасы күтілетін нақты нәтижелермен салыстырылатын тесттермен тексерілді.
Бастапқы нұсқада Ruff **1**, mypy **5** диагностика шығарды; mypy нәтижесінде
аннотациясыз функцияларды шақыру туралы екі қосымша хабарлама да бар.

- [x] Теріс сома және 0–100 аралығынан тыс пайыз қабылданбайды.

- [x] 0% және 100% шекаралары тексерілген.
- [x] Дөңгелектеу ережесі құжатталған: 101 теңгеге 50% → 50 теңге.
- [x] Функция кіріс мәндерін өзгертпейді, файлға не желіге жүгінбейді.

- [x] Ruff және mypy тексерістері өтті, негізгі жағдайлар pytest арқылы қамтылған.

## 6. Тест нәтижелері және қорытынды

[test_shop.py](test_shop.py) ішіндегі параметрленген тесттермен бірге **19 тексеру өтті**.
Бір тест бастапқы төрт ақауды қайталайды; қалған 18 тексеру түзетілген үш функцияны,
шекаралық мәндерді, жарамсыз кірістерді және толық тапсырыс сценарийін тексереді.
Бастапқы ақауларды дәлелдейтін тесттің өтуі қате кодтың дұрыс екенін білдірмейді.

Нәтиже: түзетілген кодта Ruff қатесі жоқ, mypy тип қатесін таппады, pytest
тексерулерінің барлығы өтті. Статикалық талдау, код шолуы және тесттер бірге
есептеу, тип және кіріс мәндерін тексеру мәселелерін анықтап, түзетуді негіздеді.
